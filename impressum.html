Datenschutz

Apobase ist ein Informationsangebot einer Privatperson. Es werden keine Konten, keine Profile und keine personenbezogenen Daten zu Marketingzwecken erhoben.

Server-Logs: Beim Aufruf der Website verarbeitet der Webserver technisch notwendige Zugriffsdaten (z. B. IP-Adresse, Zeitpunkt, aufgerufene Seite). Diese werden nicht für Profilbildung genutzt und nicht an Dritte weitergegeben.

Rechner-Tools: Eingaben in die Rechner (z. B. Dosierungs-Rechner, Retax-Check) werden ausschließlich lokal im Browser verarbeitet und nicht übermittelt.

AI-Chat: Fragen, die Sie im Chat („Apobase AI“) stellen, werden zur Beantwortung an den KI-Dienstleister übermittelt (API-Anfrage an einen externen Sprachmodell-Anbieter). Geben Sie im Chat daher keine personenbezogenen oder patientenbezogenen Daten ein (kein Name, keine Versichertennummer, keine Diagnosen von Personen). Chat-Verläufe werden nicht dauerhaft gespeichert; die KI-Antworten werden mit Quellen aus dem lokalen Wissensbestand erstellt.

Externe Dienste: Für die Darstellung werden Schriftarten von Google Fonts geladen; dabei kann Ihre IP-Adresse an Google übertragen werden. Details zu Datenschutz der externen Anbieter finden Sie auf deren Websites.
